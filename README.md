# Guia de viagem · Luiza & Marcos

Casamento em Franschhoek, África do Sul (19–21 nov 2026). App mobile em um único `index.html`.

- Todos os dados ficam no bloco `TRIP` no início do `<script>`.
- Os dados atuais são **EXEMPLO fictício** (viagem a Portugal). Trocar por dados reais e mudar `isExample` para `false`.
- Se o repositório for público, não coloque códigos de reserva nem telefones no HTML.
